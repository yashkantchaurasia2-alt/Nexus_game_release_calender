# Nexus - Game Release Calendar

A frontend-only web application built with React, Vite, React Router v6, TanStack Query, and the RAWG Video Games Database API.

## Features
- **Calendar View:** Explore upcoming game releases month by month.
- **Wishlist:** Save games you are interested in (stored locally).
- **Reminders:** Get browser notifications for games releasing today.
- **Dashboard:** Visualize game release data using Recharts.

## Setup

1. **Install Dependencies**
   \`\`\`bash
   npm install
   \`\`\`

2. **Get API Key**
   Get a free API key from [RAWG](https://rawg.io/apidocs).

3. **Configure Environment**
   Rename `.env.example` to `.env` and add your API key:
   \`\`\`env
   VITE_RAWG_API_KEY=your_key_here
   \`\`\`

4. **Run Application**
   \`\`\`bash
   npm run dev
   \`\`\`
